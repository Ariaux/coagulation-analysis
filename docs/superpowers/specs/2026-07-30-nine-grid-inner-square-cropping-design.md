# 九宫格最内层正方形自动切割设计

## 目标

将现有 Windows 离线桌面程序改为面向固定 3×3 模具的自动切割工具。用户把一张正面拍摄、包含完整九宫格的照片拖到程序上后，程序自动识别九个格子中最内层黑色边框包围的正方形，并仅使用这些区域进行保存和凝血定量分析。

## 使用条件

- 模具固定为用户提供的 3MF 所对应的 3×3 九宫格。
- 九宫格完整出现在照片中。
- 相机基本正对模具；允许轻微平移、缩放和旋转，不要求处理明显透视变形。
- 九个位置都必须输出，包括没有样品的空格。
- 程序运行于 Windows，必须离线工作，最终用户不需要安装 Python。

## 推荐方案

采用“整体定位 + 模板预测 + 局部边框微调”的混合方法。

纯固定比例切割容易受到拍摄距离和位置变化影响；纯轮廓识别又可能把深色样品边缘误判成黑色边框。混合方法先利用固定模具的整体结构建立稳定坐标，再把每个内框的搜索限制在小范围内，因此兼顾稳定性和精度。

## 处理流程

1. 读取图片，并生成适合检测黑色模具的灰度和二值图。
2. 检测九宫格整体外框；根据外框中心、尺寸和角度进行轻微旋转校正。
3. 将校正后的九宫格划分为固定 3×3 单元。
4. 根据模具标定比例，预测每个单元中最内层正方形的位置。
5. 仅在预测位置附近搜索四条深色边缘，并分别微调左、右、上、下边界。
6. 检查候选区域的正方形比例、尺寸一致性、行列对齐和边缘强度。
7. 将确认后的边界向内缩 2–3 个像素，避免黑框参与定量。
8. 按从左到右、从上到下的顺序输出 1–9 号图片并进行现有 ImageJ 等价分析。

边界内缩量按原图分辨率进行小比例缩放，并设置最小值，避免高分辨率照片残留粗黑边。

## 组件边界

### 九宫格定位

输入原图，输出九宫格整体的校正图像及其到原图的坐标变换。该组件只负责整体位置和轻微旋转，不处理单个内框。

### 内框检测

输入校正后的九宫格，输出九个内层正方形边界、检测分数和失败原因。检测会结合模板预测、局部灰度投影和边缘响应，不依赖格内是否有样品。

### 切割与测量

输入九个已验证边界，向内缩后切图，并复用当前的 8-bit 灰度、反相和统计测量逻辑。测量范围不包含模具黑框。

### 结果输出

输出：

- `cell_01.png` 至 `cell_09.png`：九个最内层正方形；
- `*_grid_overlay.png`：原图上的九个检测框、编号及检测状态；
- `*_heatmap.png`：3×3 测量热力图；
- `*_results.csv` 和 `*_results.json`：九格统计结果与实际切割坐标；
- 日志文件：整体定位、各格置信度和失败原因。

## 失败处理

- 找不到完整九宫格时停止分析，显示“请保证九宫格完整入镜并正对拍摄”。
- 单格边缘响应不足时，先使用相邻八格的共同尺寸和行列位置进行约束恢复。
- 恢复后仍不满足尺寸、正方形比例或对齐检查时，不生成看似正常的最终数据；预览图将该格标红并提示重新拍照。
- 空格不会被当作失败，因为检测依据是固定黑色内框，而不是样品内容。
- 输出目录不会覆盖原始照片。

## 桌面交互

桌面版保持拖放图片到程序图标的使用方式，不再显示行列选择窗口。固定使用 3×3，并在处理结束后展示检测预览和热力图，同时打开输出文件夹。

预览图中：

- 绿色框表示检测通过；
- 红色框表示检测失败或可信度不足；
- 每个框中央显示 1–9 的固定编号。

## 测试与验收

### 自动测试

- 使用合成九宫格验证 1–9 编号顺序和坐标计算。
- 对样图施加小范围平移、缩放、亮度变化和旋转，验证九个内框仍能正确定位。
- 分别测试九格有样品、部分有样品和全部为空，确保切割位置不受内容影响。
- 验证所有成功切图近似正方形、尺寸相互一致，并且边缘不包含明显黑框。
- 验证失败输入（九宫格缺失、严重裁断、明显倾斜）会明确报错而不是输出错误结果。
- 验证原有测量公式和 CSV 字段保持兼容。

### 样图验收

在用户提供的正面九宫格照片上：

- 预览框与红圈所示的最内层边界一致；
- 九张输出图只包含最内层正方形内容，不包含周围长条孔和粗黑框；
- 九格顺序为从左到右、从上到下；
- 空格也正常输出；
- Windows 打包程序在断网环境中可直接运行。

## 论文实验支持

项目同时提供独立于桌面程序的可复现实验工具，用于比较以下三种切割方法：

- 固定比例切割；
- 逐格纯轮廓切割；
- 本设计的整体定位、模板预测和局部微调混合方法。

实验工具支持两类数据：

- 带已知真值的合成九宫格，自动施加旋转、亮度、缩放、噪声、样品深浅和空格组合；
- 由研究人员人工标注内框坐标的真实照片。

评价指标包括平均 IoU、平均边界像素误差、单格成功率、整张九格全部成功率、测量均值绝对误差和单张运行时间。消融实验分别移除整体校正、局部边框微调和九格一致性约束。实验输出逐样本 CSV、汇总 JSON、论文可用图表和失败案例图；所有随机实验固定种子并记录参数。

真实照片的实验结论必须来自人工真值标注，不用主算法自己的结果充当真值，也不在没有数据时生成或填写虚构数值。

## 范围外事项

- 不处理明显侧拍造成的强透视变形。
- 不自动识别任意行列数或其他模具。
- 不改变凝血定量公式、深度学习模型或训练流程。
- 不提供联网服务或云端同步。
- 不代替研究人员收集真实照片或决定论文的统计显著性结论。
